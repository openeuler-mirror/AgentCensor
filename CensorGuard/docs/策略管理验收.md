## 保证范围

base/group 叠加以对应 enable 开关开启为前提；管理员或委托接口关闭维度时会放行。
gRPC 是组管理与事件通道，自吸附使用 agent 自己的 Unix socket 连接。
本次没有运行完整上游 DSH 应用，也没有测量性能延迟；验收覆盖仓库的接入客户端与实际 daemon。
规则 bank 切换与 domain 绑定 map 更新仍是两个阶段，不能据本验收声称全域绑定事务完全原子。
