# 部署环境检查与缺失报告

`scripts/check-deployment-env.sh` 在目标主机上记录环境，核对部署产物和随包运行依赖，最终生成
两份文本报告。检查结果供操作人员制定部署操作。

## 在目标主机运行

本指南以 openEuler 24.03 LTS SP3 aarch64 为例。离线部署包解包并校验 `SHA256SUMS` 后，
在安装运行依赖前执行：

```bash
export CG_OFFLINE="$HOME/CensorGuard"
sudo bash "$CG_OFFLINE/tools/check-deployment-env.sh" \
  --output /var/tmp/cg-deployment-check
```

`--output` 为必填项：报告目录由操作人员指定，脚本不设默认路径。省略时按参数错误退出
（返回码 `2`），不会向任何默认位置写入报告。

脚本位于 `<离线部署包>/tools/`，因此部署产物默认按相对路径识别，不需要逐个传参：

| 部署产物 | 默认查找路径（相对离线部署包根目录） | 覆盖选项 |
| --- | --- | --- |
| daemon | `release/rootfs/usr/sbin/censorguardd` | `--daemon` |
| ctl | `release/rootfs/usr/bin/censorguardctl` | `--ctl` |
| BPF 对象 | `release/rootfs/usr/lib/censorguard/enforce.bpf.o` | `--bpf-object` |
| 配置示例 | `release/rootfs/etc/censorguard/base.yaml.example` | `--config` |
| 随包运行依赖 | `rpms/runtime` | `--rpm-dir` |

源码树中运行时会退回到构建产物 `target/release/censorguardd`、`target/release/censorguardctl`、
`bpf/enforce.bpf.o` 和 `config/deployment.yaml`。离线部署包被拆开或改名时，
用 `--kit` 指定离线部署包根目录，或用表中对应选项单独指定文件。显式选项始终优先于自动识别。

环境报告首部记录每个部署产物最终使用的路径和来源（`input:`、`input-source:`，取值
`auto`/`explicit`/`missing`）。未能识别时，报告列出已查找的路径，并要求用对应选项
指定实际位置；出现 `missing` 通常说明离线部署包不完整或路径被移动。

`--output` 为必填项，报告目录由操作人员按部署变更记录要求指定；同一目录再次检查时，
脚本替换其中的上一轮报告并继续检查，而不是中止；`--keep-previous` 先把上一轮两份报告
移到 `<目录>/previous/<时间戳>/` 保留，供变更记录对照。脚本只清理自己的两份报告和
临时区，目录内其他文件不受影响；路径为符号链接、普通文件，或目录非空且不是本脚本
上一轮生成的目录时，脚本拒绝写入并提示换用其他路径。目录权限为 `0700`，文件默认仅
检查用户可读。

默认目标架构为 `aarch64`；`--arch x86_64` 用于其他对应部署产物，`--arch any` 只取消
目标架构限制，用户态 ELF 仍须与实际主机匹配。BPF 对象单独按 eBPF ELF 检查。
`--timeout 20` 控制每条诊断命令的最长执行秒数，可设为 1 至 300。
`--rpm-dir` 指定平铺存放运行依赖 RPM 的目录。

检查在目标主机上完成。准备机提前准备运行依赖、构建材料、检查脚本和验证记录；
准备过程参见 [准备机离线准备指南](离线准备指南.md)，部署步骤参见
[目标主机离线部署指南](离线部署指南.md)。

## 两份报告

| 文件 | 内容 |
| --- | --- |
| `deployment-environment-report.txt` | 实际系统环境、完整已装 RPM 清单、命令和文件采集结果、返回码、耗时、标准输出和错误、部署产物及随包 RPM 元数据 |
| `deployment-operation-report.txt` | 缺失汇总、各项缺失是否具有阻断性、随包候选依赖、待确认事项、处理方法和参考命令 |

检查临时文件在报告完成后清理，最终目录保留上述两个文件（使用 `--keep-previous` 时
另有 `previous/<时间戳>/` 归档）。运行内核 BTF 的文本解析
结果写入环境报告；内核配置内容也在报告中保留。二进制采集内容仅供检查期间解析。

| 标记 | 含义及处理 |
| --- | --- |
| `BLOCK` | 阻断性缺失：已确认缺少必需能力、部署产物不兼容、安装目录不可用，或已确认缺失的必需依赖没有随包候选 RPM。报告列出可选处理方法，部署前需处理 |
| `MISSING` | 目标主机缺少依赖，随包存在兼容架构的候选 RPM；核验包签名、预览安装事务，安装后复查 |
| `UNKNOWN` | 证据不足，可能是权限、诊断命令缺失、挂载不可见或查询失败；补充证据后判断 |
| `WARN` | 需复核事项或可选采集失败，如已有安装 |
| `PASS` / `INFO` | 已验证的静态条件或补充记录 |

随包覆盖依据实际 RPM 的名称、架构和 Provides 元数据，不以文件名或固定版本号推断。
同名候选包仍需复核签名、完整依赖闭包、事务影响和安装后的符号版本兼容性。
现有库满足要求即可使用。实际缺失且随包未覆盖时，应在准备机补充对应依赖后分发；
内核能力缺失按报告中的内核处理方法解决。

诊断工具缺失会标记信息不足并给出候选工具包，其他项目继续。部署所需命令缺失且
离线部署包没有候选包时，会明确记录该项在当前部署流程中的阻断性。

| 退出码 | 含义 |
| --- | --- |
| `0` | 检查和报告生成完成；环境结论见报告 |
| `2` | 参数使用错误（含缺少 `--output`、`--kit` 指向的目录不存在） |
| `3` | 无法建立或替换报告目录、写入报告、清理检查临时区 |

环境缺陷不改变脚本退出码。操作人员应阅读第二份报告；存在阻断性缺失时按部署变更流程
停止部署并处理。完成依赖安装或其他环境调整后，重新执行同一条命令复查即可，同一目录
的报告会被替换为最新一轮结果；需要保留每轮记录时使用 `--keep-previous`。

## 采集范围与运行边界

采集 OS、运行内核、架构、页大小、CPU、内存、负载、cgroup、磁盘、inode、挂载、已装
RPM、systemd、权限与资源限制、SELinux、lockdown、Secure Boot、BPF sysctl、网络接口、
路由、监听端口、已有项目安装，以及显式指定的配置。

cgroup 资源限制按当前进程实际归属和挂载方式采集。脚本支持 cgroup v1、cgroup v2 和
混合挂载：v1 使用 `memory.limit_in_bytes`、`memory.usage_in_bytes`、CPU quota/period
和 `pids.max`，v2 使用对应的 `memory.max`、`memory.current`、`cpu.max` 和 `pids.max`。
某个控制器或可选文件未暴露时只记录说明，不将其判为部署阻断。

兼容性依据本机实际能力、部署产物 ABI 和可读证据判断：

- 核对运行内核配置、活动 BPF LSM、BTF 中 31 个必需 LSM 目标，以及 4 个 tracepoint。
- 记录 BPF helper 和 map 类型声明，具体程序的可用性在运行验收时由 verifier 确认。
- 检查用户态 ELF 和 BPF ELF 的架构、段、动态加载器、运行库闭包、符号和符号版本。
- 记录安全机制状态和权限信息，结合实际加载验收确认兼容性。

脚本通过 Bash 和系统诊断命令采集本地信息，写入范围为报告目录中的两份报告
（及检查期间的 `raw/` 临时区，结束后删除）。每个诊断命令
设超时及输出上限，正常 Bash 模式下单个输出文件上限为 64 MiB。ELF 解析结果按路径
缓存以复用公共库检查，单个依赖闭包最多分析 256 个文件，超出时记录信息不足。
`timeout` 不可用时，相应外部采集记为信息不足；脚本仍生成报告。

检查期间保持主机当前启动状态。内核配置或活动 LSM 缺失时，报告优先列出兼容
主机、暂缓部署等选择；需要内核或引导调整时，由系统管理员安排维护窗口和回退方案。
挂载、包安装及系统变更的参考命令均由操作人员确认后执行。

静态报告覆盖可读取和解析的环境证据。BPF 加载、CO-RE、verifier、实际服务权限和
业务性能仍需部署验收；故障注入和压力测试安排在验收环境。

报告包含主机名、IP、用户组、挂载路径、启动参数、软件包和显式指定的配置，应按部署环境的
信息管理要求保存，对外分享前需脱敏。RPM 软件源保留配置路径及 SHA-256。操作人员审阅后可封存：

```bash
sudo tar -C /var/tmp -czf /var/tmp/cg-deployment-check.tar.gz cg-deployment-check
sudo sha256sum /var/tmp/cg-deployment-check.tar.gz
```
